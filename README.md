# 游戏 BGM 曲库

古典作曲家和当代 DJ 两条线的游戏配乐，共 55 首，风格库里的 41 位（组）作曲家和 12 组 DJ 曲风每种都有一首。可在浏览器里看五线谱、点曲名直接播放、换配器（30 种音色）、换速度、加整体效果（混响、合唱、镶边、相位、自动滤波、磁带延迟、低保真）、导出 MP3。

- 网页：打开 GitHub Pages 地址（`index.html`），手机和微信内置浏览器都能播放
- MP3：`mp3/` 目录，160 kbps / 44.1 kHz 立体声，循环 2 遍、结尾淡出
