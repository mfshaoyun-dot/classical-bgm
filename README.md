# 游戏 BGM 曲库

古典作曲家和当代 DJ 两条线的游戏配乐，共 14 首，可在浏览器里看五线谱、试听、换配器、换速度、导出 MP3。页面下方的风格库列出了全部候选作曲家与 DJ（41 位/组作曲家、12 组 DJ 曲风），已写的可以点击跳转。

- 网页：打开 GitHub Pages 地址（`index.html`），手机和微信内置浏览器都能播放
- MP3：`mp3/` 目录，160 kbps / 44.1 kHz 立体声，循环 2 遍、结尾淡出
