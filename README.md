# 古典 BGM 曲库

按巴赫、莫扎特、帕赫贝尔、贝多芬、舒伯特的写法写的 8 首游戏配乐，可在浏览器里看五线谱、试听、换配器、导出 MP3。

- 网页：打开 GitHub Pages 地址（`index.html`），手机和微信内置浏览器都能播放
- MP3：`mp3/` 目录，160 kbps / 44.1 kHz 立体声
